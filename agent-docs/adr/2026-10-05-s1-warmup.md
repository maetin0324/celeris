# S1 latency の計測区間に関する付記

ADR-0081 の S1 latency は、各画面への初回遷移を計測外で 1 回 warm-up した後の shell 遷移を測る。初回遷移には chunk 読み込み等の cold path が含まれ、共用 host の負荷により delay 0 の測定値が大きく揺れるためである。

各画面で delay ループの前に、同じ親画面・リンク（リンクのない画面は同じ popstate 経路）から delay 0 で遷移する。cold path の URL・heading・data 所要時間は標準出力と `WEB_LATENCY_RESULTS` の各画面 JSON の `coldPath` 欄に残し、退行を観測できるようにする。既存 gate は warm-up 後に delay 0/5/10 秒で行う画面数・閾値（URL/heading 300ms、delay 差 100ms）・retries 0 を維持する。
