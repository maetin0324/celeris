# ADR 2026-10-15: Jev 分類段の daemon 配線

- 日付: 2026-10-15
- 状態: 採用（D1 Config 欄・D2 ApiKeyProvider・D3 tick 連携（`daemon/classify_tick.rs`）まで実装。D4 は既存の apply_lane_assist 経路で、一連試験は `daemon/classify_tick/e2e.rs`）
- 関連: 2026-10-15-mlsys-min-decision-assisted（D1 fixed へ戻る・D4 credential 待ち）、
  2026-10-15-mlsys-min-routing-policy（ClassificationBoard・lane_assist）、ADR-0030（secret）、
  2026-10-11-breaking-changes-by-default

## Context

分類段（`daemon/classify_stage.rs` の `ClassificationStage` / `JevClassifier`）は daemon に未配線で、Config に Jev の欄が無く、
`ClassificationBoard` が空のため `decision_assisted` でも全件 `not_attempted` になる。dispatcher・store に LLM 呼び出しを入れない
境界（既存 `classify_stage`）は保ったまま配線する。

## Decision

### D1. Config: `[jev]` 欄（既定無効）

- `[jev] enabled = false` が既定。欄・表が無ければ従来の挙動は不変（分類段を作らない）。
- 欄: `enabled`, `endpoint`, `model_id`, `timeout_ms`, `max_retries`, `backoff_base_ms`, `backoff_max_ms`, `cache_max_entries`,
  `breaker_failure_threshold`, `breaker_cooldown_ms`, `secret_id`（既定 `jev_api_key`。値ではなく secrets dir 内の名前）。
  既定値は `jev_classifier::JevConfig::default()` と同一（単一の出所）。schema / prompt の版は設定にせずコードで固定する。
- `deny_unknown_fields`。未知欄・型違い・不正値（http(s) でない endpoint、`~` の latest alias、空 model_id・secret_id、
  `timeout_ms = 0`、`breaker_failure_threshold = 0`）は読み込みエラー。**無効のときも検証する**（有効化した瞬間に起動できない設定を残さない）。
- 鍵の値は config に書けない（そういう欄が無い＝未知欄エラー）。

### D2. ApiKeyProvider（後続 WU jev-key）

secrets dir（`[secrets]`）の `secret_id` を読む `ApiKeyProvider` を daemon 側に置く。値は log・event・API・エラー本文に出さない
（`Debug` は伏字、エラーは secret id のみ）。`[secrets]` が無い・鍵が未登録なら `JevError::MissingKey` 相当を返し、
既存の `apply_lane_assist` → `enter_credential_wait` へ渡る。

### D3. tick 連携の境界（後続 WU jev-tick）

- 分類は tick ループ側（daemon 層）で、ready の WU を `ClassificationStage` に通して `ClassificationBoard` に置く。
  dispatcher・store・task-dispatch は board を**読むだけ**で、Jev・HTTP・LLM を呼ばない。
- `routing.mode = fixed` または `jev.enabled = false` のときは分類しない（board は空のまま、従来どおり）。
- 分類は dispatch をブロックしない。tick の中で待つのは bounded（`timeout_ms` × retry）で、breaker open 中は即 fixed へ戻る。
- 同じ WU を同じ入力で再分類しない（`cache_max_entries` の cache と board の entry で冪等）。

### D4. エラーの扱い: 鍵再登録要求にするのは認証系だけ

- 鍵未登録・401/403 → credential 待ち（既存経路。登録通知後に同じ WU が一度だけ再開）。
- 429・予算不足・5xx・timeout・不正応答 → fixed へ戻る記録（`fell_back_to_fixed{reason}`）。**鍵再登録は要求しない**。
  429 / 予算不足は鍵の誤りではなく、人に鍵を入れ直させても直らないため。

### D5. routing.mode は変えない・`[llm_sources.jev]` は不要

- `routing.mode` は本番 `fixed` のまま。`decision_assisted` はこの ADR では全体に切り替えない。
  対象を絞る切替（例: 特定 project / genre だけ decision_assisted）が必要になったら、**付記で提案する**（今は提案のみ。実装しない）。
- `[llm_sources.jev]` は不要。Jev は harness が使う LLM source ではなく、daemon が lane 選択入力のために呼ぶ分類 API で、
  route 選択・model catalog・account pool の対象外。endpoint と鍵は `[jev]` と secrets dir だけで足りる。
  source として宣言すると route_selection の候補に混ざる恐れがあるため置かない。

## Consequences

- config 差分は `[jev]` の追加のみ（既定無効なので本番 config を書き換えなくても挙動は変わらない）。有効化は人が config と鍵登録で行う
  （手順は jev-e2e WU の進捗「本番への移行」節）。
- 消す旧い仕組みは無い（新規欄の追加）。

## 付記 2026-10-15: 実 API の schema 不一致と 4xx の記録（task 01M50XES8WJQ3MRVPEVQQQZHSK）

本番で実 Jev 呼び出しが全件 `fell_back_to_fixed{client_error}` → `breaker_open` になった。公式 schema
（OpenRouter Decisions API `POST /api/alpha/decisions`）との突き合わせで次を決めて実装した。

- A1. choice の `criteria` は必須の object（ラベル → 1 文の説明）で送る（`jev_classifier::question::questions`）。
  specificity の各ラベルの説明は instructions からラベルごとの説明へ移した。旧形（文字列の配列）は残さない。
- A2. verifier（`daemon/jev_verifier.rs` の `ping_body`）の noul は `criteria` を省く（旧 `"criteria": "yes"` は不正）。
- A3. `FallbackReason::ClientError` は `ClientErrorDetail { status, code, message }` を持つ（`Copy` をやめた）。
  401/403/429 以外の 4xx の応答本文から `error.code`・`error.message`（200 文字まで）だけを読み、鍵・入力本文は持たない。
  分類段の記録は `client_error:<status> code=<code> message=<message>` で、400（schema）と 402（残高不足）を区別できる。
- A4. credential 検証の `classify_http_status` は 400 を `VerifyOutcome::RequestRejected` にする（Transient にしない）。
  検証要求の schema 不備は再試行しても直らないので backoff 再試行に入れず、同じ鍵では再検証しない（release の差し替えで
  daemon が再起動すれば判定は消える）。鍵の不備ではないので再登録も求めない。402 は従来どおり Transient。
- A5. 試験の fake server（`crates/jev-classifier/tests/jev_fake_server.rs`）は要求を公式 schema の形で検査し、
  合わなければ台本に関わらず 400 `{"error":{"code":"invalid_request",…}}` を返す。
