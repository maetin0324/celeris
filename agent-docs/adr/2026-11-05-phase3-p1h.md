# P1-H 統括 CoS の比較評価の境界

## 決定
- A4 の 3 分類・認可・拒否の実装は置き換えない。実モデルの失敗を観測していないため、推測で production prompt や policy を変えない。
- worker から別の LLM を起動しない。今回は既存 A4 の fixture/replay と、外部 operator が残す観測のオフライン集計まで行う。実 LLM の旧新比較は未実施とする。
- 比較器は相談の分析・提案・必要な追問、読取の正確さ、実装修正の起票と元 thread への要約を、原票を参照した独立採点の真偽値で受け取る。LLM の自己申告から成功を作らない。認可違反は他の得点に関係なく失敗にする。
- 旧新は case・repeat・model・harness・account・dataset が同じ組だけ比較する。欠けた腕と欠測値は null として残し、観測 0 や成功にしない。fixture と実 LLM の観測は混ぜない。
- A4 の読取試験は、固定の返答でなく API の 3 件の状態から集計する。別の 4 件目を除外し、原票に取得 id・状態・返答を残す。これは試験の不足の修正で、実 LLM の正確さを証明するものではない。
