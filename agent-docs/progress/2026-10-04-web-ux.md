## 提案

### dark mode の提案

DESIGN.md「Dark mode（提案）」と web-0004 のとおり、提案だけにして実装はしない（toggle・依存・`dark:` の生色は足さない）。

- **方式**: `web/styles.css` の同じ semantic token（`--color-*`）の値を、`:root[data-theme="dark"]`（と将来の `prefers-color-scheme`）で差し替える。feature 側は token 名のまま変えない。
- **token の対（案）と contrast**（WCAG 相対輝度で計算、文字 4.5:1・枠 3:1 が目標）:

| token | light | dark 案 | dark の contrast |
|---|---|---|---|
| background / foreground | `#f4f7f9` / `#20303c` | `#121a21` / `#e3eaef` | 14.46:1 |
| surface / foreground | `#ffffff` / `#20303c` | `#1a242d` / `#e3eaef` | 12.95:1 |
| muted-foreground（surface 上） | `#536572` | `#9aabb8` | 6.66:1（background 上 7.44:1） |
| input（枠、surface 上） | `#758593`（3.80:1） | `#6f8291` | 3.96:1（background 上 4.41:1） |

- **段階**:
  1. token の対を DESIGN.md に足す。contrast の表は自動で計算し直す（e2e `focus-motion.spec.ts` の枠 3:1 の計算を dark にも当てる）。
