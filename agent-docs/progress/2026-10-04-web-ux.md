### after-r4 を見て残った課題

reviewer の 4 点は画像で解消を確認した。ただし画面全体は **可 138・要修正 13・保留 31**（look-a 57/0/7、look-b 41/7/12、look-c 40/6/12）。要修正・保留を全画面の合格として扱わない。

1. **狭い幅の情報の発見性**: `_providers-360.png`・`_providers-390.png`・`_providers-412.png` では一覧の右列が見えず、横移動の手がかりも無い。`_tasks_T1-360.png` の「成果物」tab も右端で切れる。`_graph-360.png`・`_graph-390.png`・`_graph-412.png` は横に続く graph の手がかりが見えず保留。

4. **状態変種の案内と一貫性**: `empty-_graph-1440.png`・`empty-_graph-360.png` は空の graph 枠に案内が無い。`forbidden-_tasks-1440.png`・`forbidden-_tasks-360.png` は一覧自身に「一覧へ戻る」が出る。`loading-_providers-360.png` は接続状態が 2 行に折れる。`stale-_-360.png` は警告が出ると会話枠が約 40px に縮み、行が半分切れる。`stale-_tasks-{1440,360}.png` と `stale-_tasks_T1_runs_R1-{1440,360}.png` は header 以外に stale の印がなく保留。

6. **画像で判定できない操作**: 削除時の確認、reviewing 状態の判断操作、閉じた本文、ソフトキーボード時の入力、読み上げ名・focus 順は目視画像だけでは可にしない。before の正常データが無い比較も同様に限界を明記する。
