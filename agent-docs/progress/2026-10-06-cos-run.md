### 本番切替に人の手順が要る点

- CoS 専用 role の harness/LLM source/model/account の実機固定（account 固定・provider 固定）は本番 config への書込みなので、人が `~/.config/celeris` を編集して daemon を再起動する（本 WU は config を変更しない）。
- 切替 transaction（`cos_v1` ルート版・source cursor・旧 pending の CoS item への結び）と旧 CoS run の drain/stop は daemon 再起動を伴うので、人の selfdeploy 手順（release → verify → promote の安全確認付き）で実施。
- 旧 daemon への rollback は新 schema を直接開かず、停止時 backup から戻す手順として人に示す（ops-docs 担当）。
