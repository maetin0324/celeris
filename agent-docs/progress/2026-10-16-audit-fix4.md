- 保証: 新規投入は「確定消費 + in-flight 予約」が残予算を下回るときだけ（budget.rs `admit`）。usage 欠測・更新待ち・cancel 停止未確認では予約を維持し、消費 0 として解放しない。wall は task の wall 上限（と job walltime）で硬く抑える。
