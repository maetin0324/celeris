# A1 案件ごとの durable event/wakeup orchestration（Rust の最小実装）

完了日: 2026-11-04

結論: ADR 2026-11-04-project-controller の A1 を実装した。events・停滞・cron・人の操作から案件ごとの wake を作り、
coalesce → lease → 判定 → tx1（CAS）→ 冪等な効果、の流れを Rust に置いた。判定は A1 の既定（効果なし）で、TS との
接続は A3。本番は変えていない（release・config・DB・systemctl に触れていない）。

### 既存機構の再利用（別のイベントストア・状態機械を足していない）
- wake の元は `events`（`events_since` と `feed_cursor` の `project_wake`）、`StagnationFinding`、cron（ADR-0131）、人の操作。
  `project_wakes` は派生で、task の状態は写さない（I1・I2）。
- root の作成は `task_ops::add::build_task_with_roles` と `task_idempotency_keys`（I5）。CoS 入力は `chat_system_queue_once` と
  `cos_thread_ensure_tx`（I10）。子待ちの判定は `task_ops::delegate::child_wait::awaited_children`、root の判定は
  `task_ops::root_done::is_root_done`・`task_core::is_root_task` をそのまま読む（I15）。
- dispatcher・store は LLM を呼ばない（I3）。controller が起こしうる LLM は既存の CoS run だけ。

### 依頼の仕組みと試験
| 仕組み | 実装 | 試験 |
|---|---|---|
| project 別 cursor | `project_controller_state.event_cursor`（判断に畳んだ events.id の最大）＋全体 cursor `feed_cursor.project_wake` | 全試験（cursor を戻す再配送は `redelivery_10x`） |
| coalescing | 最初の wake から `coalesce_secs`（30） | `project_wake_coalesce`（30 秒に 20 wake → decide 1） |
| lease | instance id と期限（`lease_secs` 60）。draining・disk 不足は段ごと呼ばない | `project_wake_lease_takeover`、`project_wake_two_instances` |
| next_wake_at | 判定の `next_wake_after_secs` → 期限で評価 | （A6 が使う。A1 は列と評価の条件） |
| revision/CAS | tx1 で lease・mode・`human_epoch`・`revision` を照合 | `project_wake_cas_stale`、`project_wake_human_races_apply` |
| idempotent create_task | key `pc:<project>:<root.key>`、task と key を 1 tx | `project_wake_redelivery_10x`、crash 6 件、`two_instances` |
| retry/backoff | 60×2^(n-1)、上限 3600、`max_retries` 5 を超えたら `blocked` | `project_wake_backoff`（60,120,240,480,960 → blocked、以後 decide 0） |
| 再起動復元 | tx1 で効果を判断の行に書き、`pending` を tick の頭で実行し直す | `project_wake_crash_b1`〜`b6` |
| backpressure | 1 tick の評価 `max_evaluations_per_tick`（2）、CoS 入力は案件ごと未処理 1 件 | `project_wake_backpressure`（50 案件 → 1 tick ≤ 2、25 tick で全部） |
| Manager と人の競合 | `human_epoch`（人の操作で +1 と wake）、mode を上げるのは人だけ | `project_wake_human_races_apply`、`project_wake_api_cos_may_only_turn_it_off` |
| 既定で無害 | 行なし・`off` は wake を積まない | `project_wake_off_is_inert`（event の差分 0） |
| shadow | 判断は記録、効果は `suppressed` | `project_wake_mode_shadow` |
| 待機中の LLM 0 | wake が無ければ decide しない | `project_wake_idle_7days`、`project_wake_cron_idle` |
