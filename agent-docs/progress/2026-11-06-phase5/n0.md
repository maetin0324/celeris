## 未解決
- `Usage` は cache の TTL を分けない。予算判定は大きい方に倒したが、保存値 `usage.cost_usd`（実験の道具・表示・campaign）は 5 分 TTL の単価のまま。
- Haiku 5.5・Opus 5 の単価の行は過大（止まる向き）。直すには `PRICE_TABLE_VERSION` を変える人の判断が要る。
- codex の `gpt-6-*` は単価が無く、使った案件の予算は費用不明で止まる（`[budget_rates]` を人が書くまで）。

## 提案
- `Usage` に TTL 別の cache creation（`ephemeral_1h`）を足し、`estimate_cost_usd` と予算判定を同じ式にする。`PRICE_TABLE_VERSION` を上げる
  ので、K2/K4 の凍結の後に人が時期を決める。
- 実験の道具の USD を、保存値の和ではなく daemon と同じ再計算（`GET` の API で `run_budget_cost` の値を出す）にそろえる。
