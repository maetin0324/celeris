2. `compare.py config-check --tier llm --manifest m.json --plan p.json --llm-config c.toml --out <dir>` が exit 0。
3. `compare.py preflight --tier llm --only 7,8 --approval <承認 file> --llm-config c.toml …` が exit 0。

5. 合否（[runbook.md](runbook.md) の N3）: 2/2 が `error` なし、両方の `cost_usd` が数値（`usd_unknown` 0）、`spent.usd` ≤ 承認の `max_usd`。
