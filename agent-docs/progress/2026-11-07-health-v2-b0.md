## 配送の失敗
結論: B0 の配送は 2026-11-07T15:42:09Z に release 準備（prepare）の verify で落ちた。原因は、本番の昇格前の current の scripts に snapshot_db.py が無かったこと。修正入りの release が昇格した後、この WU が `/local/celeris/state/current/scripts/snapshot_db.py` があることを読み取りだけで確かめた。

- 失敗行（`/local/celeris/state/releases/.deliveries/01M6TYVJSPEYA2P8B7G56HSQ73/<配送した commit>/prepare.log` の 62〜63 行）:
  - `python3: can't open file '/local/celeris/state/current/scripts/snapshot_db.py': [Errno 2] No such file or directory`

  - 同じ log で release の build と gate は通っている（`release ready`・`done: ... schema_version=120`）。落ちたのはその後の verify だけ。
- 原因: 配送は本番の current の scripts にある prepare.sh を使い、prepare.sh は同じ dir の verify.sh を起こす（`scripts/selfdeploy/prepare.sh` の `bash "$script_dir/verify.sh"`）。verify.sh は同じ dir の snapshot_db.py を起こす（`scripts/selfdeploy/verify.sh` の DB snapshot）。昇格前の current は、release.sh が scripts/ に *.sh だけを写していた版で作った release で、snapshot_db.py を同梱していなかった。
