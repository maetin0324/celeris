## Task の受け入れ条件と根拠
試験の件数は、unit reclose が自分の提出時の HEAD に対して `cargo nextest list -p task-worker -p task-dispatch -p task-core` が出した関数名を数えた（task-worker の `change_rules_` 25 件、task-dispatch の `health_review_` 80 件、task-core の `design_brief_` 7 件・`health_review_` 9 件）。その後の Rust の変更は limits-doc の doc comment 1 行だけで、試験は増減していない。reclose-docs は数え直していない。合否は各 unit の記録（その unit の提出時の HEAD で実行）による。limits-doc は task-core の逆依存の crate 全部を `test-affected.sh` で走らせ、`7981 tests run: 7981 passed`（[limits-doc.md](2026-11-07-health-v2-g2/limits-doc.md)）。
