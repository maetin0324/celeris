## ADR との違い（ADR の末尾の付記に書いた）
1. 組の finding は、循環の finding が existing（節点の数が base を超えない）のときだけ出す。新しい循環・併合した循環は循環の finding が既に fail 級なので二重の報告を避け、既存の試験 3 件（deps.cycle の finding がちょうど 1 件）を保つ。
2. `super::` は inline の `mod` block の深さも数える。数えないと block の中の `super::y` を `crate::y` と誤って解決し、誤った辺を作る。
3. 論理 module の表は検査の対象の Rust の file 全部（試験・道具も）に作る。`crate::x` が module かの判定を今までと同じに保つため。辺の元は本体の file だけ。
