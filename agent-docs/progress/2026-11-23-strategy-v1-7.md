## 提案

- gateway の `relay.js` が daemon の 403 をすべて 502 `daemon_auth` にするので、案の採否と署名の拒否の理由が画面に届かない。「daemon の token の認証の失敗（401）だけを

- 概要の chat の link に `message` を足すと、chat の route の強調（D4）を概要から使える。足すなら概要の e2e の URL の期待も変わる。
